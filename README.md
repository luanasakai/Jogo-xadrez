# ♔ Jogo de Xadrez

Jogo de xadrez desenvolvido para a disciplina de Tópicos em Programação.

## ⚒︎ Tecnologias Utilizadas

- **Python** — linguagem base do projeto
- **PySide6 (Qt6)** — interface gráfica
- **SQLAlchemy** — ORM para o banco de dados
- **PyMySQL** — conexão com o banco de dados MySQL

## 📁 Estrutura do Projeto
Jogo-xadrez/
├── main/        # Lógica principal do jogo e peças
├── banco/       # Modelos e configuração do banco de dados
├── UI/          # Arquivos de interface gráfica (.ui e .py)
└── README.md

## ▶️ Como Executar
```bash
# Clone o repositório
git clone git@github.com:luanasakai/Jogo-xadrez.git
cd Jogo-xadrez

# Instale as dependências
pip install pyside6 sqlalchemy pymysql

# Execute o jogo
python main/menu.py
```
